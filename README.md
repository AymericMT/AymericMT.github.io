# Portfolio — Aymeric Millerioux--Tamain

Portfolio professionnel développeur web & applicatif, déployé via GitHub Pages.

🌐 **[Voir le portfolio en ligne](https://aymericmt.github.io)**

## Stack technique

HTML · CSS · JavaScript · Three.js · WebGL

## Fonctionnalités

- Ciel étoilé 3D interactif (planétarium WebGL avec données BSC5 réelles)
- Constellations avec labels et survol
- Mode observation — navigation libre dans le ciel étoilé
- Navigation SPA (Single Page Application) sans rechargement
- Visionneuse PDF intégrée
- Menu hamburger responsive (mobile)
- Barre de progression au défilement
- Pause automatique de l'animation en arrière-plan

## Sections

- **Accueil** — présentation, stack, liens
- **Expériences** — stages en entreprise (Inore Groupe Impression, Fédération des Centres Sociaux de la Nièvre)
- **Projets** — applications développées (ICGO, GSB)
- **Veille tech** — IA dans le domaine médical
- **Compétences** — tableau de synthèse E5
- **Contact** — formulaire, CV, GitHub, LinkedIn

## Déploiement

Le portfolio est déployé automatiquement via GitHub Pages depuis la branche `main`.  
Le fichier `index.html` est le point d'entrée unique.

## Documents

Le dossier `documents/` contient les PDF référencés dans le portfolio (CV, rapports de stage, fiches de situation…).  
Ces fichiers ne sont pas versionnés — à ajouter manuellement après clonage.
